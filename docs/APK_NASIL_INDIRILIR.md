# MeloTR APK derleme ve indirme

GitHub'da **Actions** sekmesini açın. `MeloTR Android APK` iş akışını seçin.

İş akışı otomatik başlamadıysa **Run workflow** düğmesine basın.

Başarılı bir derlemenin sayfasında **Artifacts** bölümünden `MeloTR-v0.1.0-APK` dosyasını indirin. ZIP içindeki `app-release.apk` Android'de yüklenebilir.

Bu sürüm yalnızca telefondaki yerel müzikleri çalar. YouTube müziğini indirmez.
